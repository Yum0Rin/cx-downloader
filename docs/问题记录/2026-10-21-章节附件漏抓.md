# 2026-10-21　章节附件漏抓：42 章只认出 16 个文件

## 现象

用户反馈：某门课（42 个章节）界面上明明有一堆课件文档，工具扫描结果只有 **16 个文件**，
而且正好是「视频」那一章的 15 个 + 一页 PDF，其余章节全是「0 个附件」。

## 定位过程

逐章请求 `/mooc-ans/knowledge/cards` 的**原始 HTML**，与浏览器渲染后的 DOM 对照，
发现同一个附件在不同章节里有三种写法：

| 写法 | 典型场景 | 旧解析 |
| --- | --- | --- |
| `<iframe class="ans-attach-online" data="{...}">` | 老模板，部分视频章还在用 | 命中 |
| `<div class="ans-attach-ct"><iframe class="downloadfile" data="{...}">` | 新模板，多数课件 | 漏 |
| `<iframe class="ans-module ans-insertdoc-retract" module="insertdoc" data="{...}">` | 编辑器里插进正文的文档（docx/ppt/pdf） | 漏 |

旧代码按 `class="...ans-attach-online..."` 抓标签，只有第一种能命中。

同一门课逐章统计：

- 老写法：16 个
- 新写法：41 个
- 合计（按 objectid 去重）：**99 个**

## 根因

学习通改版，附件容器的 class 名换了。解析逻辑绑在 class 名上，模板一动就整类文件消失。
**与登录账号无关**：换号前后扫的是同一份页面，漏的数量一样。

## 影响面

- 漏掉的几乎全是文档类（pdf / docx / doc / pptx / ipynb / csv / xlsx / py / npy）。
- 视频章恰好还走老模板，所以视频没漏 —— 表现为「文档全没了、视频还在」，很容易被误判成
  「账号不对」或「老师没传」。

## 修复

不再认 class 名，改成扫**所有带 `data="{...objectid...}"` 的标签**再解析 JSON：

```
data="(\{[^"]*?objectid[^"]*?\})"
```

三种写法一次覆盖，按 objectid 去重（同一附件在 `ans-attach-ct` 里可能既被外层容器、
又被内层 iframe 各带一份 data）。

## 验证

同一门课、同一 Cookie，修复后扫描结果 16 → 99，与课程门户「教学资源」列出的条目数一致。

## 顺带修掉的坑：账号切换不透明

手动填的 Cookie **优先级高于** 读 Firefox 登录态。浏览器里换了号、手动 Cookie 还留着，
工具就会一直用旧号扫，界面上却只显示「手动 Cookie（N 字符）」，看不出是哪个号。

现在：

- 登录态那行会显示**当前账号姓名**（取 `passport2.chaoxing.com/mooc/accountManage` 的
  `#messageName`，失败就留空，不影响扫描）；
- 新增「换号」按钮：清空手动 Cookie、重新读 Firefox 的 `cookies.sqlite`、刷新账号名。
