# 2026-10-21　视频任务点为什么跳过、后来怎么加的口子

## 为什么一直跳过

视频任务点在章节页里的对象和文档不是一套：

```json
{
  "objectid": "ad7e…ffa1", "filename": "1.mov", "length": 849054495,
  "http":     "https://s2.cldisk.com/sv-w8/video/…/sd.mp4?at_=…&ak_=…&ad_=…",
  "download": "http://d0.cldisk.com/download/ad7e…?at_=…",
  "dtoken": "3560…", "duration": 821,
  "mp3": "https://s2.cldisk.com/sv-w8/video/…/mp3/",
  "screenshot": "…/snapshot.jpg", "thumbnails": "…/thumbnails/"
}
```

它**没有 `pdf`**（文档那套转码），早期代码在「没有可下地址」时按「视频，不支持」标跳过，
后来即使有了 `download`，只要模式是「仅 PDF」也一样被跳过。所以表现是「视频永远不下载」。

## 两种取法的差别（实测同一门课）

| 文件 | 转码 mp4（`http`） | 原件（`download`） | 比值 |
| --- | --- | --- | --- |
| 1.mov | 33.8 MB | 809.7 MB | 24x |
| 2.mov | 41.5 MB | 360.9 MB | 8.7x |
| 课堂练习.mp4 | 19.1 MB | 133.9 MB | 7.0x |
| C23时间序列基本性质1(1).mp4 | 12.8 MB | 87.3 MB | 6.8x |

- **转码 mp4**：服务端压过的，普通播放器直接放，画质被压（一般 480p/720p 级）。
- **原件**：老师上传的那份，画质码率最好；`.mov` 在 Windows 上可能要 VLC/PotPlayer。

## 实现

- `process_one(..., want_video, video_original)`：
  - `video_original` → 取 `download`，存原名（`.mov`）；
  - 否则取 `http`，存 `<stem>.mp4`；
  - 没有 `http` 的视频自动退回 `download`，不报失败。
- GUI：选项区「视频也下载」开关 + 「转码 mp4 / 原件」下拉（关闭时下拉置灰）。
- CLI：`--video` / `--video-original`。

## 验证

- 转码分支：35.4 MB / 10.7 s，落 `1.mp4`（URL 为 `sd.mp4`）。
- 原件分支：URL 为 `download/<objectid>`，落 `1.mov`（只验了地址选择，没真下 800MB）。
- 31 个视频里个别没有 `http`（如 `3.mov`、`课堂内容.mp4`），走的是退回原件的路径。
