# 2026-10-21　重扫全标「新文件」、自动跳过失效

## 现象

修好附件漏抓后，用户下完 43 个文件再重扫，**99 个全标「新文件」**，自动跳过一次都没生效。

## 定位

落盘结构（仅 PDF 模式 + 课程名/分组两级）：

```
保存目录\课程名\基础信息\xxx.pdf
```

而查重走的是 `resolve_course_files()`：

```python
f["target"] = predict_name(f["name"], key)          # 原名 xxx.docx
f["path"]   = os.path.join(outdir, f["target"])     # outdir = 保存目录\课程名
f["exists"] = os.path.exists(f["path"])
```

两处对不上：

1. **名字**：仅 PDF 模式落的是 `<stem>.pdf`，查重找 `<原名>.docx`；
2. **目录**：文件在「分组 / 章节」子目录里，查重只在课程根目录找。

于是本地明明有，`exists` 恒为 False —— 界面全标「新文件」，自动跳过形同虚设。

## 修复

- 两种候选名都看：`[原件名, <stem>.pdf]`，顺序按当前模式决定；
- 新增 `dir_of` 回调，按当前层级勾选算每项落点（GUI 用 `course_path()`）；
- 命中的是 PDF 转码时，比内容改用 `pdf` 地址（拿原件比字节数永远不等）；
- 下载模式进 `scan_key`：换模式 = 查重结果作废，重扫时重新判定。

## 验证

同一门课、同一保存目录、仅 PDF + 课程名/分组：

| | 结果 |
| --- | --- |
| 修复前 | 99 个全「新文件」 |
| 修复后 | 68 个「已存在且相同」，31 个新（31 个视频 + 之前失败项） |
