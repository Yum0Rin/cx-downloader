## 1. 为什么改

v3 的流程是「粘课程页 → 扫描 → 直接全下」，有三个问题：

1. 不能挑：一门课 11 个附件里只想要 3 个，也得全下。
2. 不查重：本地已经下过的课件，再扫一次还是重下 66 MB。
3. 「读取浏览器课程页」按钮依赖本机 Firefox 的会话快照 —— 把工具发给同学，
   别人机器上大概率没有这套环境，按下去只会报错。

需求：**先扫描 → 列表里勾选（默认全选）→ 下载**；并且能识别出「本地已有且内容相同」
的文件自动跳过；把依赖本机环境的那颗按钮去掉。

## 2. 改了哪些文件 / 核心差异

### 2.1 `cx_download.py`

| 新增 | 作用 |
| --- | --- |
| `resolve_name` / `predict_name` | 统一「最终落盘文件名」的推导，扫描阶段就能预判路径 |
| `parse_hsize` | 把 `10.65 MB` 这类展示字符串换回字节数（估算合计用） |
| `local_head_md5` / `remote_head_md5` / `compare_with_remote` | 判「是不是同一份文件」 |
| `resolve_course_files` | 给扫描结果补上「落到哪个路径 / 本地有没有 / 是否同一份」 |
| `describe_object` | 给裸 objectid 补文件名和大小，好在列表里显示 |

关键改动：

- **`process_one` 的命名逻辑抽成 `resolve_name`**，保证「扫描时预判的路径」和
  「下载时实际写的路径」严格一致（否则查重会误判）。
- **删除 mozLz4 / 读 Firefox 标签页那一整段**（`_lz4_block_decompress`、`read_mozlz4`、
  `firefox_open_tabs`、`firefox_course_tabs`）。对应按钮已撤，留着就是死代码。
- **`extract_objectids` 先剔除课程页链接**（v3 已有，本次沿用）。

**为什么不用接口给的 `crc`**：`/ananas/status/` 返回的 `crc` 是 32 位 hex，但实测
**不是文件内容的哈希** —— 拿已下好的文件算 md5 / sha1 都对不上（应该是云盘内部对象号）。
好在 `d0.cldisk.com` **支持 HTTP Range**，所以「同一文件」的判据定为：

> 字节数相同 **且** 前 64 KB 的 md5 相同

代价只有 64 KB 流量，不用整包重下。而且**只有本地已存在同名文件时才发起比对**，
全新文件零额外请求。

### 2.2 `cx_download_gui.py`

- **流程改为 扫描 → 勾选 → 下载**。新增「④ 任务列表」卡片：每行
  `[勾选框] 分组 / 章节 · 文件名 …… 大小 [新文件 / 内容相同 / 内容不同]`，
  配「全选 / 全不选 / 反选」，右侧实时显示「已选 x/y　待下载 n 个　约 X MB」。
- **逐项「替换 / 跳过」的按钮撤掉了**。只保留一个总开关
  **「自动跳过相同文件」**（默认开）：开了就跳过内容相同的，关了同名文件一律重下覆盖。
  内容不同的文件一律按覆盖处理。
- **删掉「读取浏览器课程页」按钮**及其实现，避免在别人机器上报错。
- **布局从单列改成左右两栏**：左列放输入 / 保存目录 / 选项（高度固定），
  右列放任务列表（撑满）+ 日志。原来的单列在 175% 缩放 + 2560×1600 下会被裁掉底部。
- 「扫描」按钮现在同时支持课程页链接和裸 objectid。
- 设置项 `overwrite` 换成 `auto_skip`（默认 `true`），旧配置文件仍能读。

## 3. 改动前后关键结果对比

测试课程：`261学期 示例课程`（courseid=123456789），12 个章节、11 个任务点、66.44 MB。

| 场景 | 改动前（v3） | 改动后（v4） |
| --- | --- | --- |
| 首次扫描 | 直接开始下载 11 个 | 列表 11 项，**全部勾选**，标注「新文件」 |
| 只想要其中 10 个 | 做不到 | 取消勾选 1 个 → **下载 10/10，成功 10** |
| 同目录再扫一次 | 全部重下 | **10 个判为「内容相同」，待下载 1 个**（就是上轮没下的那个） |
| 自动跳过关掉 | — | 待下载 11 个，全部重下 |
| 手工往某个文件尾部追加 7 字节再扫 | — | 该文件判为「内容不同」，`will_download=True`，会被重下 |
| 文件字节数 | 与接口 `length` 一致 | 与接口 `length` 一致（下载逻辑没动） |
| 命令行版 | 支持课程页 | 行为不变，实测 11/11 成功，耗时 2.4s |

查重的判定链路（`compare_with_remote`）：先比字节数，不一致直接判「不同」；
一致再取远端前 64 KB 算 md5 与本地比 —— 实测两份文件都返回 `True`。

## 4. 对下游交付物（论文/报告/接口）的口径影响

- **命令行参数完全向后兼容**，`cx_download.py` 原有调用方式、输出口径都没变。
- GUI 配置文件的 `overwrite` 键改名 `auto_skip`（默认 `true`）；旧配置里残留的
  `overwrite` 会被忽略，**首次启动默认开启「自动跳过相同文件」**。
- 新增依赖：**无**。`hashlib` 是标准库。
- 判重只读取远端 64 KB，**不会因为查重而产生完整下载**。
- 开始菜单 `超星文件下载器.lnk` 指向未变，**照常可用**。

## 6. 已知限制

- **课程页扫描依赖登录态**。优先读本机 Firefox 的 `cookies.sqlite`；
  读不到时请在「Cookie」框里粘贴浏览器 Cookie（任何浏览器都能复制到）。
  这次撤掉的只是「读取浏览器**标签页**」那颗按钮，读 Cookie 的机制保留。
- **「内容相同」的判据是 字节数 + 前 64 KB md5**。理论上存在前 64 KB 相同、
  后面不同、且总字节数也相同的文件会被误判为相同 —— 对课件场景可以忽略。
- **只抓文档类任务点**（`ans-attach-online`）。视频、测验、讨论没有可下载文件，显示 0 个。
- **「下载内容」是持久化设置**。若上次选了「仅 PDF」，课程页下载也只拿 PDF。
