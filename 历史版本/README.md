# 历史版本存档

每做一次**推倒重来式**的改动（重构、换算法、改口径、大规模重写），
都先把**改动前那一版**原样打包到这里，再动手改。

目录命名：`<改动名>-vX-日期/`

每个目录里有两样东西：

1. **改动前的源码**（原样存档，不参与当前交付）
2. **`README-历史版本说明.md`**，写清四件事：
   - 为什么改（触发改动的问题 / 需求变更）
   - 改了哪些文件、核心差异是什么
   - 改动前后的关键结果对比（数字、指标、结论差异）
   - 对下游交付物的口径影响 + 怎么回滚

顺序铁律：**先快照 → 再改动 → 后验证**。

## 回滚

想回到某个版本，把对应目录里的源文件覆盖回仓库根目录即可：

```powershell
Copy-Item 历史版本\资料页扫描-v5-20260916\*.py . -Force
```

注意每个目录存的是**它自己那一版改动之前**的状态，所以
「回滚到 v5」= 用 v5 目录里的文件（那是 v6 动手前的样子）。
