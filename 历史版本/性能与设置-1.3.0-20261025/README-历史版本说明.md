# 性能与设置-v13-20261025（改动前快照）

> 本目录内容 = **改动前**那一版（cx_download.py / cx_download_gui.py / CHANGELOG.md / README.md）。
> 要回退就用本目录的源码覆盖仓库根目录同名文件。

## 为什么改

- 默认的朱砂红在深色模式下偏亮，用户希望可换主题色（最好有色盘）。
- 扫描大课程要 30 秒以上（逐章串行请求），重复扫同一门课也一样慢。
- 下载失败后要手动重新勾选；关掉程序后任务列表就没了。

## 改了哪些文件

| 文件 | 改动 |
| --- | --- |
| `cx_download_gui.py` | 新增设置弹窗（主题色色板 + 系统色盘、外观、扫描缓存、检查更新、GitHub/Release）；header 的 GitHub 按钮改为「设置」；失败重试按钮；队列保存/恢复 |
| `cx_download.py` | 版本号 1.3.0；`scan_course()` 加 10 分钟扫描缓存、章节并发（workers=4） |
| `CHANGELOG.md` / `README.md` | 1.3.0 说明 |

## 前后对比

| 指标 | 改动前 | 改动后 |
| --- | --- | --- |
| 24 章课程扫描 | ~33 秒 | ~10.5 秒（并发） |
| 10 分钟内重复扫描 | ~33 秒 | ~0 秒（缓存） |
| 主题色 | 固定朱砂红 | 6 个预设 + 系统色盘，默认黛蓝 |
| 下载失败 | 手动重新勾选 | 「重试失败 (N)」一键重试 |
| 关闭程序后 | 列表清空 | 自动恢复任务与勾选状态 |

## 口径影响

- 扫描缓存只保存附件列表（objectid/名称/章节），不保存本地路径和查重结果；查重仍按当前设置重新做。
- 恢复队列不恢复保存目录（落点始终按当前设置），只恢复任务、勾选、模式和目录层级。
- 主题色需要重启程序生效（设置里有「保存并重启」）。

## 怎么回滚

用本目录的 `cx_download.py`、`cx_download_gui.py` 覆盖仓库根目录同名文件，重新打包。
