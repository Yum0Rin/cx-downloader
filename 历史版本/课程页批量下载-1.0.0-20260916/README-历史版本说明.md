# 历史版本说明：课程页一键批量下载（v3）

- **改动名**：课程页批量下载-v3
- **日期**：2026-09-16
- **目录**：`历史版本/课程页批量下载-v3-20260916/`
- **本目录内容**：改动**前**的 `cx_download.py` 与 `cx_download_gui.py`（原样存档）

---

## 1. 为什么改

旧版只能「拿到单个文件的预览页链接 / objectid → 下载」。要下一门课的课件，得先在
学习通里一个个点开任务点、复制 11 条链接、再粘回来，很笨。

需求：**在课程页一键把整门课的任务点附件全下下来**，并且从开始菜单就能启动。

---

## 2. 改了哪些文件 / 核心差异

两个文件都改了（`cx_download.py` 命令行版同步受益）。

### 2.1 `cx_download.py`（核心）

新增「课程页扫描」整节：

| 函数 | 作用 |
| --- | --- |
| `extract_course_urls` / `parse_course_url` | 从文本里认出课程页链接，取 `courseid / clazzid / cpi` |
| `find_firefox_profiles` / `load_firefox_cookies` / `firefox_cookie_header` | 读本机 Firefox 的 `cookies.sqlite`，复用登录态 |
| `read_mozlz4` / `firefox_open_tabs` / `firefox_course_tabs` | 纯 Python 解 `mozLz4`，读 Firefox 会话快照里的标签页 |
| `fetch_course_chapters` | 拉章节树（含「基础信息 / 教学课件」分组名） |
| `fetch_chapter_attachments` | 逐章抠出 `ans-attach-online` 里的 `objectid / name / type / size` |
| `scan_course` | 串起来，返回 `{name, courseid, files[]}` |

改动点：

- **`extract_objectids` 先剔除课程页链接**。课程页 URL 的 `enc=` 本身就是 32 位 hex，
  不剔除会被当成 objectid 一起下载（下下来必然是 403）。
- **`process_one` 增加 `name_hint`**：课程页里显示的文件名（如「第1章 操作系统概述.pptx」）
  优先于存储名，但**扩展名仍以接口返回为准**，避免名字和真实格式对不上。
- **`main()` 支持课程页链接**：输入里出现课程页链接就自动扫描，按「课程名」建子目录，
  再走原来的 `/ananas/status/` → `d0.cldisk.com` 直链下载。
- **Cookie 默认取 Firefox 的**（原来默认不带）。对公开预览文件无影响，对登录受限文件更稳。
- **`sanitize` 归一化 `\u00a0`**：网页标题里的 `&nbsp;` 会变成普通空格，否则目录名带个隐形字符。

### 2.2 `cx_download_gui.py`（界面）

- 输入框标题改为「链接输入（预览页 / objectid / 课程页）」。
- 新增 **「读取浏览器课程页」**：把 Firefox 里开着的课程页标签一键填进输入框。
- 新增 **「扫描课程」** 按钮：扫描 → 日志里逐条列出「分组 / 章节 → 文件名 大小」，
  并把保存目录自动切到 `<原目录>/<课程名>`，输入框右侧显示「课程 N 个」。
- **「开始下载」** 改为汇总两类任务：输入框里的链接 → 保存目录；
  扫描出的课程附件 → 各自课程子目录（`process_one` 本来就按调用传 outdir）。
- 扫描/下载互斥，互斥期间对应按钮置灰；关窗时两者都会被检查。

## 3. 改动前后关键结果对比

测试课程：`261学期 示例课程`（courseid=123456789），共 12 个章节、11 个任务点。

| 项 | 改动前 | 改动后 |
| --- | --- | --- |
| 拿到 11 个 objectid | 手工逐个点开复制 | 自动扫描 |
| 下载结果 | 11/11 成功，66.44 MB | **11/11 成功，66.44 MB（完全一致）** |
| 文件大小 | 与接口 `length` 一致 | 与接口 `length` 一致 |
| 文件命名 | 接口存储名（如 `Chapter7_输入输出系统.pptx`） | 课程显示名（`第7章 输入输出系统.pptx`），**大小/字节完全不变** |
| 落地目录 | 手动指定 | `Downloads/超星下载/<课程名>/` |
| 耗时 | — | 扫描 ~1.0s + 下载 1.7s |

逐字节核对：11 个文件的字节数与接口 `length` 全部相等
（46841 / 33000 / 11163283 / 4007849 / 8397419 / 3105516 / 9688484 / 4313147 / 12456508 / 8832144 / 7625403）。

**回归**：老的预览页链接、裸 objectid、混合输入的行为完全不变；
课程页链接不会再被误当成 objectid。

## 4. 对下游交付物（论文/报告/接口）的口径影响

- 命令行参数**完全向后兼容**，`cx_download.py` 原有调用方式不变。
- 新增文件**默认命名口径变化**（存储名 → 课程显示名）只发生在「课程页扫描」这条路径上；
  直接给 objectid/预览链接时，命名仍用接口存储名。
- 新增依赖：**无**（`sqlite3 / configparser / glob / shutil / tempfile / urllib.parse` 都是标准库；
  LZ4 解压是自己实现的，没装 `lz4` 包）。
- 启动方式：开始菜单 `超星文件下载器.lnk` → `pythonw.exe cx_download_gui.py`，
  工作目录设为脚本目录（保证 `import cx_download` 命中）。

---

## 5. 回滚方式

把本目录里的 `cx_download.py`、`cx_download_gui.py` 覆盖回上一级目录即可，
无需改任何配置（设置文件 `~/.cx_download_gui.json` 两个版本通用）。

---

## 6. 已知限制

- **依赖 Firefox 登录态**。课程页扫描要读 Firefox 的 `cookies.sqlite`；
  没装 Firefox 或没登录会报「登录态失效」。此时可用界面上的「Cookie（一般留空）」手填。
- **「读取浏览器课程页」有几十秒延迟**：Firefox 的会话快照不是实时写的。
  刚打开的页面可能读不到，等一会儿或切一下标签页再试。
- **只抓文档类任务点**（`ans-attach-online`：pptx / docx / pdf / xlsx 等）。
  视频、测验、讨论类任务点没有可下载文件，会显示 0 个附件。
- **注意「下载内容」默认值是持久化的**。若上次选了「仅 PDF」，本次课程页下载
  也只会拿 PDF 不拿原件 —— 想下原件请切到「仅原件」或「原件 + PDF」。
