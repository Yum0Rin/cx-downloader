# 历史版本：更新自更新加固（v1.4.4 / 2026-11-14）

> **本目录内容 = 改动前（v1.4.3）的那一版。** 回滚就是把这里的 4 个文件覆盖回仓库根目录。

## 为什么改

2026-11-14 复盘「版本更新提示 + 自动安装」时确认了 6 个问题，按严重程度排：

1. **替换失败静默**：`_apply_update` 生成的 bat 在 `copy` 连续失败 10 次后仍然
   `goto copied` 直接启动旧 exe，用户只看到程序「重启了」，版本其实没变，也没有任何提示或日志。
   装在 `Program Files`（无写权限）或被杀软锁文件时必现。
2. **更新包不能续传**：`_auto_update` 用 `open(tmp, "wb")` 从 0 写，且 5 分钟硬超时。
   慢网下 14.5MB 下到一半超时，再点一次还是从 0 开始，`%TEMP%` 里的残包不复用。
3. **引导不足**：更新弹窗只有一句「退出后自动覆盖并重启」，没写权限要求、杀软、失败怎么办、
   设置是否保留；设置页的「更新下载代理」只有 placeholder；README 没有「更新」章节。
4. **系统代理不生效**：`urllib.request.build_opener()` 只读环境变量，Windows 系统代理
   （Clash/v2ray 的「系统代理」开关）不会被使用，用户必须手填那一格。
5. **无内容校验**：只有「大小 + `MZ` 头」，GitHub API 已经返回 `digest`（sha256）却没用上。
6. **「关闭」与「不再提示」语义不清**：点关闭下次启动还会弹。
