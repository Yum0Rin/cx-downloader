# 历史版本说明：移除用不到的网络设置（1.4.7 / 2026-11-14）

## 为什么改

用户明确「根本用不到」这套设置：更新链路里那一格手动输入框、自动读取系统网络设置的逻辑，
在校园网 / 境内直连场景没有任何作用，却在界面和文档里反复出现相关字眼。
本次把功能、界面、文案、文档一次性清掉，并同步升版本号、重打包。

## 改了什么（本目录存档 = 改动前）

| 文件 | 改动前 | 改动后 |
| --- | --- | --- |
| `cx_download.py` | 有读取 Windows 网络设置的那个函数；`__version__ = 1.4.6` | 删除该函数；注释改中性；`__version__ = 1.4.7` |
| `cx_download_gui.py` | `download_update_package()` 带网络设置参数并据此建 opener；设置页有输入框和对应变量；保存 / 读取相关配置字段；一键更新里读取配置与系统值 | 参数与分支删除，下载一律直连；设置页整行删除；保存字段删除；调用改为直连 |
| `selftest.py` | 必需接口清单含 `system_proxy` | 移除该必需符号 |
| `README.md` / `CHANGELOG.md` / `AGENTS.md` | 多处描述性字眼 | 全部改写 / 删除，新增 `[1.4.7]` 段 |
| `dist\超星文件下载器.exe` | 15,575,026 B，v1.4.4 产物 | 重新打包，见根目录 `dist\` |

## 口径影响

- 配置文件 `~/.cx_download_gui.json` 里已有的相关字段不再被读取；留在文件里也不影响任何功能，
  不需要手工清理。
- 更新下载一律直连。境外不通时仍走「境内更新源」和「从本地文件更新」两条兜底，能力不变。
- 读取系统网络设置的能力被**移除**，属于功能删减，不是 bug。
- `历史版本/` 下更早的其它快照保持原样，未做字眼清理 —— 它们是回滚依据，改了就失去意义。

## 怎么回滚

1. 把本目录的 `cx_download.py` / `cx_download_gui.py` / `selftest.py` / `README.md` /
   `CHANGELOG.md` / `AGENTS.md` 覆盖回仓库根目录；
2. 需要连 exe 一起回退时，把 `dist-超星文件下载器-v1.4.4-before.exe` 复制成
   `dist\超星文件下载器.exe`（以及桌面 `大学の残骸\超星文件下载器.exe`）；
3. 重新跑 `python selftest.py --no-network` 与 `build.ps1 -NoNetwork` 确认。
