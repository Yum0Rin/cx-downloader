## 1. 为什么改

之前只扫**章节页**的任务点附件。但学生端的**「资料」页**（课程页导航里的「资料」，
`pageHeader=3`）里还有一批独立上传的文件 —— 比如
`261学期 示例课程` 这门课，章节任务点只有 6 个，而「资料」里躺着
6 个 CSV（合计 835 MB），之前完全扫不到。

需求：**用同一套「扫描 → 勾选 → 下载」的流程，把「资料」页也做了**。

---

## 2. 改了哪些文件 / 核心差异

### 2.1 摸清的接口（两个入口完全独立）

| | 章节页 | 资料页 |
| --- | --- | --- |
| 列表 | `/mooc2-ans/mycourse/studentcourse` → 逐章 `/mooc-ans/knowledge/cards` | `/mooc2-ans/coursedata/stu-datalist` |
| 进子层 | `knowledgeid=<章节id>` | 同一个 URL 带 `dataId=<文件夹id>&type=1` |
| 下载 | `/ananas/status/<objectid>` → `d0.cldisk.com` 直链 | 行内隐藏的 `/coursedata/downloadData?dataId=..&classId=..` |

「资料」页**本身就是文件列表**，递归展开文件夹就列全了；每个文件行的
`<li class="operate_down">` 里藏着下载直链，直接抓出来用。
`enc` 参数和课程页 URL 上的那个**不是同一个**，从资料页的隐藏 input 里取。

### 2.2 `cx_download.py`

| 新增 | 作用 |
| --- | --- |
| `_parse_data_rows` | 从资料页 HTML 抠出每行（文件夹 / 文件 / 教师课件入口） |
| `_fetch_data_page` | 取资料页（根目录 / 指定文件夹） |
| `scan_course_data` | 递归展开文件夹，返回全部文件 |
| `download_data_one` | 下载资料页里的一个文件 |
| `remote_probe` | 一次 Range 请求同时拿「远端总字节数」+「前 64KB md5」 |
| `compare_url_with_local` | 按 URL 判重（资料页的文件没有 objectid） |

改动点：

- `compare_with_remote` 改为复用 `remote_probe`（原来只取 md5，长度另算）。
- `resolve_course_files` 的查重按类型分派：有 `url` 走 URL 版，否则走 objectid 版。
- `download()` 增加 `cookie` 参数 —— 只对 chaoxing 自己的域名传，
  **不把课程 cookie 发给 `d0.cldisk.com`**。
- CLI 的任务从 `(objectid, 目录, 名字)` 改成 `(类型, 载荷, 目录, 名字)`，
  `main()` 里对课程页同时扫章节 + 资料；新增 `--no-data` 可只扫章节。
- 「教师课件」那一行是跳章节课件的入口，**跳过不扫**（章节那边已经有了）。
- `parse_course_url` 增加 `classId` 别名（课程页写 `clazzid`，作业/考试页写 `classId`，
  同一个值）—— 这样从作业页、考试页复制链接过来也能直接扫。

### 2.3 `cx_download_gui.py`

- 扫描时对每个课程页同时跑章节 + 资料两个扫描，结果并到同一个任务列表，
  靠标签前缀区分：`课程章节 / 绪论 · xxx.pptx` vs `资料 / dj2_preprocess_data · coupon.csv`。
- 任务项增加 `kind`（`oid` / `data`）与 `payload`，下载时按类型分派。
- 日志行 `(N 页)` 只在有页数时显示（资料文件没有页数）。
- **修了一个窗口定位 bug**：`_fit_geometry` 原来只设尺寸不设位置，窗口默认由系统
  随便摆，高一点的窗口会被摆到屏幕外，底部（操作行 / 日志）直接看不见。
  现在连位置一起算：居中并夹在屏幕内，高度预留从 70 提到 110。

## 4. 对下游交付物（论文/报告/接口）的口径影响

- **CLI 默认行为变了**：给课程页链接时现在会**多扫出「资料」页的文件**。
  想要旧行为加 `--no-data`。原有参数与输出格式不变。
- 新增依赖：**无**（仍是标准库）。
- 判重依然只读远端 64 KB，不会因为查重产生完整下载。
- 开始菜单 `超星文件下载器.lnk` 指向未变。

## 6. 已知限制

- **资料页可能有超大文件**（实测单文件 470 MB）。扫描只列清单不下载，
  下载哪些完全由勾选决定 —— 注意看「约 X MB」那行再点开始。
- **资料页的文件夹递归有深度上限**（`max_depth=8`）和去重保护，防止异常结构打转。
- 「资料」里的**文件夹本身不下载**，只下里面的文件。
- 资料文件没有 PDF 变体，「下载内容」选「仅 PDF」时资料文件仍下原件。
- 「资料」页的下载直链是**行内 HTML 里带出来的**，如果学习通改版把
  `operate_down` 这个 class 去掉，需要跟着改 `_parse_data_rows` 里的正则。
