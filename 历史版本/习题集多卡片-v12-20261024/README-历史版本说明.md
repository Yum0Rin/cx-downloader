# 习题集多卡片-v12-20261024（改动前快照）

> 本目录内容 = **改动前**那一版（cx_download.py / cx_download_gui.py / CHANGELOG.md）。
> 改动后的正式版在仓库根目录；要回退就用本目录的 `cx_download.py` 覆盖回去。

## 为什么改

实测发现某门课的**习题集**扫不出来。

定位结果：学习通把一章拆成多张「卡片」（PPT / 习题集 / 案例 / 课程思政…），
每张卡用 `num` 索引（0 起）。旧的 `fetch_chapter_attachments()` 把 `num` 写死为 `0`，
每章只扫第一张卡，习题集和后面的讲解视频、实验文档整张漏掉。

## 改了哪些文件

| 文件 | 改动 |
| --- | --- |
| `cx_download.py` | `fetch_chapter_attachments()` 逐张请求 `num=0,1,2…`，越界（`<title>` 空 + 无附件）连续两张才停；附件新增 `card` 字段记录卡片名 |
| `CHANGELOG.md` | 新增 `[1.2.1]` 条目 |
| `docs/问题记录/2026-10-24-习题集扫不出来.md` | 新增问题记录 |

GUI 未改（扫描结果的结构兼容，多出来的就是同一章其他卡片里的文件）。

## 前后对比（实测课程）

| 指标 | 改动前 | 改动后 |
| --- | --- | --- |
| 扫描文件数 | 24 | 108 |
| 习题集 PDF | 0 | 17 |
| 扫描耗时 | ~10 秒 | ~33 秒（24 章） |

## 口径影响

- 扫描列表会多出同一章其他卡片里的视频任务点（mp4）。未开「视频也下载」时，
  下载阶段仍按原逻辑跳过，不影响文档下载。
- 每章多 2~7 次 `cards` 请求，扫描变慢但结果更全。

## 怎么回滚

用本目录的 `cx_download.py` 覆盖仓库根目录同名文件，重新打包即可。
