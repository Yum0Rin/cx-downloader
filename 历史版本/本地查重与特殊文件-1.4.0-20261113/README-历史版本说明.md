# 本地查重与特殊文件-1.4.0-20261113

## 为什么改

以前扫描只按「当前保存目录 + 目录层级」算出来的**那一个落点**去查本地是否已有文件。
实际使用中，本地课程目录常被手动整理进 `知识点/课件讲义`、`作业`、`课程文档` 等子目录，
层级和工具算出来的不一致；课程目录名也可能带/不带「261学期」前缀。
结果就是：文件明明在本地，工具仍标成「新文件」，甚至重复下载。

另外，视频、安装包、压缩包、超大文件体积远大于普通课件，混在一个列表里容易误勾。

## 改了啥

1. 新增 `find_local_course_dir()`：按课程名在保存根目录下找**已有的**课程文件夹，
   容忍「261学期」前缀、括号别名、简称（最长公共子串打分）。
2. 新增 `collect_local_files()`：递归收集课程文件夹下的全部文件（不论子目录层级）。
3. 新增 `match_local_file()`：先按「去 (1)(2) 后的主名」匹配，再按**字节数**兜底匹配。
4. 新增 `check_local_course()` / `summarize_check()`：扫描平台文件并对照本地，
   给出「已有 / 有更新 / 缺失 / 特殊」汇总。
5. 新增 `is_special_file()`：识别视频、安装包、压缩包、超过阈值的大文件。
6. 新增 `fetch_course_list()` / `course_time_status()`：一次取账号全部课程，
   按开课/结课时间判断进行中/未开始/已结束。
7. CLI 新增 `--check-local`、`--local-root`、`--include-special`、`--large-mb`、`--report-json`。
8. GUI 新增「扫描全部课程」按钮：列出账号全部课程（标状态、按开课时间排序），
   勾选后批量检查；特殊/大文件单独成组、默认不勾，检查完弹窗询问是否一并下载。
   粘链接的「扫描」也改为递归查本地。
9. 任务列表和课程选择列表改为 Canvas 虚拟绘制（参考 tksheet）：数据在内存里，
   画布只画视口附近几十行的圆角横条 / 文字 / 勾选框，滚动只移动画布；千行级不再
   逐行建控件。长文件名按像素截断，不压到大小 / 状态列。
10. 「扫描全部课程」的课程选择支持按开课日期 / 结束日期筛选（`YYYY-MM-DD`，可留空；
    结束日期前有复选框，默认不勾选）；只检查当前可见且勾选的课程。
11. 「扫描 / 扫描全部课程」的 ⓘ 装进同一个按钮容器，提示框按实时鼠标位置就近弹。
12. 底部操作栏先占住底部并设最小窗口高度，窗口压小时按钮不会被挤掉。

## 前后对比

- 改前：只查工具算出的精确落点；目录名/层级一变就误判「新文件」。
- 改后：在整个课程文件夹里递归查，主名或字节数任一命中即算已有；
  特殊/大文件单独提示，不默认下载。

## 口径影响

- 「已有」的判定更宽松：同一章不同扩展名（如 PDF 版 vs PPT 源）仍按主名视为已有，
  不会重复下载。若需要原始格式，可在结果里手动勾选。
- 特殊/大文件默认不下载，需要用户在弹窗里确认或手动勾选。

## 怎么回滚

把本目录下的 `cx_download.py`、`cx_download_gui.py`、`CHANGELOG.md`、`README.md`
拷回仓库根目录覆盖即可。
